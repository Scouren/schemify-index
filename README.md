# Schemify package index

Listings for the Schemify store: plugins and themes. Authors add or update a listing by pull
request; Scouren reviews it, signs the index and publishes it with a copy of every file at
`store.scouren.com`. The Schemify app reads only that signed index.

The listing format, the checks and the author tools (`schemify plugin new / check / preview /
publish`) are described in the Schemify plugin docs: https://github.com/Scouren/Schemify-Plugins
